dhcpd is a DHCP server: it hands out addresses to computers on one of its interfaces, which must have a fixed address. Leases are saved, so computers keep their addresses when the server restarts.

It runs in the background, as a service (see "help service"), and starts with the computer. What it hands out is in its log.

The settings dhcpd.lease (seconds, default 3600), dhcpd.dns (DNS servers, separated by commas), dhcpd.domain and dhcpd.gateway are passed on to clients.

ex:
"dhcpd start top" hands out .100 to .199 of the network on the interface "top", from now on. "dhcpd top" does the same.
"dhcpd start top 50 80" hands out .50 to .80.
"dhcpd stop" stops it, and it doesn't start with the computer.
"dhcpd start" starts it again, as it was.
"dhcpd status" says how it's doing, and what it's handed out.
"dhcpd run top" hands out addresses in the foreground instead, until Ctrl+T is pressed.
