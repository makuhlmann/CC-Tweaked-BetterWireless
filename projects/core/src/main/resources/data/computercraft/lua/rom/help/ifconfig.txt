ifconfig shows this computer's network interfaces and hostname, and sets how interfaces get their addresses. Every modem is an interface. By default, wired interfaces ask a DHCP server for an address, and give themselves a link-local one (169.254.x.y) if there isn't a server. Wireless and ender interfaces have no address until you give them one, so idle computers don't flood the airwaves. Settings are saved, so they apply when the computer starts.

ex:
"ifconfig" shows every interface, its address, and how much traffic it has seen.
"ifconfig top 10.0.0.1/24" gives the interface "top" the fixed address 10.0.0.1, on network 10.0.0.0/24.
"ifconfig top dhcp" makes "top" ask a DHCP server again.
"ifconfig top none" gives "top" no address at all.
"ifconfig top band low" makes a wireless or ender modem use the long-range low band after the computer restarts.
"ifconfig top psk correct horse" encrypts everything on "top" with the passphrase "correct horse". Every computer on the same network needs the same passphrase, and others can't read or join it. Anyone with the passphrase can read everything, so use secure connections for anything sensitive.
"ifconfig top psk none" stops encrypting "top".
