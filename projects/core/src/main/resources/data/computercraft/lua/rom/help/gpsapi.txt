Functions in the GPS API:
gps.locate( timeout )

The locate function listens for nearby GPS hosts, which send their positions every two seconds, until it has heard enough of them or the timeout (3 seconds unless given) passes. If it hears enough to determine this computer's position then x, y and z co-ordinates will be returned, and how far off they may be (0 if exact: a computer which moves while it listens is found less well), otherwise it will return nil. If GPS hosts do not have their positions configured correctly, results will be inaccurate.
