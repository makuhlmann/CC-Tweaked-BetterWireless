Functions in the GPS API:
gps.locate( timeout )

The locate function listens for nearby GPS hosts, which send their positions every two seconds, until it knows where the computer is to within a block, or has heard each host twice, or the timeout (5 seconds unless given) passes. If it hears enough to determine this computer's position then x, y and z co-ordinates will be returned, and how far off they may be (0 if exact, as for a computer which stays put; one which moves works out how it's moving, which is exact if it goes steadily in a straight line, but it may have turned since, which the error allows for), otherwise it will return nil. If GPS hosts do not have their positions configured correctly, results will be inaccurate.
