cellcore sets up and manages a cellular network's core: it lets phones attach, gives them addresses, carries their packets between cells and the rest of the network, and keeps their messages. The core runs in the background and starts with the computer, so this computer stays free, and the core keeps running while it's managed. The operator's keys stay in this computer's enclave.

Cells (and computers which manage the core from elsewhere) wait until they're allowed here. Allow one by its computer ID, and check the fingerprint shown here matches the one the cell shows.

ex:
"cellcore setup ACME 10.64.0.0/16 555" sets up the network ACME, giving phones addresses in 10.64.0.0/16, and starts it. Its number prefix is 555 (it may be left out, and set later with "cellcore numbers"): other networks' phones reach ACME's at 555 followed by their number, once the networks exchange messages.
"cellcore" shows how the core is doing, and who is waiting to be allowed.
"cellcore stop" stops the core, and "cellcore start" starts it again. "cellcore restart" starts it afresh: cells and phones lose it for a moment, and phones get new addresses.
"cellcore log" shows what the core has done lately, and keeps showing new lines until Ctrl+T is pressed.
"cellcore add ACME-0042 0042" makes an activation code for a subscriber with the number 0042, for a day.
"cellcore subscribers" lists the subscribers, and where their phones are.
"cellcore remove ACME-0042" removes a subscriber.
"cellcore set ACME-0042 barred yes" cuts a subscriber's phone off, and refuses it, without removing them. "cellcore set ACME-0042 roaming no" keeps them to this network's own cells.
"cellcore cells" lists the cells, and the computers allowed in or refused.
"cellcore allow 7" allows computer 7, which is waiting, after checking its fingerprint.
"cellcore deny 7" refuses computer 7 from now on.
"cellcore networks" lists the agreements with other networks: what each network does for the other, and how it's going.
"cellcore network BETA" shows the agreement with BETA. "cellcore network BETA carry on" has this network carry BETA's phones at its cells (roaming): BETA's phones then use this network's cells where they can't hear their own, keeping their addresses. "cellcore network BETA roaming on" lets this network's phones use BETA's cells, if BETA carries them. "cellcore network BETA messages on" has this network's phones exchange messages with BETA's. Each is undone with "off".
"cellcore network BETA core 10.0.0.2" says where BETA's core is: this core connects to it, and keeps connecting. One connection between the two cores carries everything they agree, so only one of them needs to know where the other is ("core none" waits for the other to connect). The first time, BETA's administrator allows this core with "cellcore allow", as they would a cell, after checking the fingerprint "cellcore network" shows here. Allowing it makes the agreement there too, accepting what this network offers.
"cellcore network BETA home on" has this network's phones treat BETA (which carries them) as home: they aren't roaming there, use its cells as readily as this network's own, and may use it even if they mayn't roam. That's for national roaming, and for a network with a core but no cells of its own (a full MVNO), which its hosts carry: its phones even activate through their cells. "cellcore network BETA home off" makes BETA a roaming partner again.
"cellcore numbers 555" sets this network's number prefix, without restarting the core. Other networks' cores hear of it at once.
Phones send to the phones of a network they exchange messages with by number, with that network's number prefix in front: "666" and "0042" make "6660042". Both networks need number prefixes, and different ones. Messages go over the secure connection between the cores, which say whether they took each one. While BETA's core can't be reached, messages for it wait here, and go when it's back. A number with no prefix this network knows can't be reached.
"cellcore network BETA forget" drops the agreement with BETA. BETA's core ends it from its side with "cellcore deny".
"cellcore roaming" and "cellcore peers" list the networks this one roams with, and exchanges messages with. "cellcore carry", "uncarry", "partner", "peer" and "unpeer", as older versions had them, still work, and change the agreements.
"cellcore remote 10.64.0.1 add ACME-0043 0043" does the same on the core at 10.64.0.1, from another computer (even a phone, through the network itself). That computer waits to be allowed the first time. Everything but "setup" and "start" works this way, over a secure connection. Programs can manage a core too, with net.cell.manage.
