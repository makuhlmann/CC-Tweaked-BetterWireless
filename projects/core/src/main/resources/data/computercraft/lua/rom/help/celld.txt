celld runs a cell of a cellular network: a tower which phones attach through. It runs in the background, starts with the computer, and keeps the computer running when nobody is nearby. It reaches the network's core over any route (a cable, a radio link, or the cell's own computer), and tries again if it loses the core.

Put the cell's modem above the roofs around it. With nobody nearby, only the cell's chunk and the eight around it are loaded, and the radio sees buildings beyond them as solid rock up to their roofs: a cell lower than those can lose its far phones whenever nobody is near it.

The cell keeps its cores and settings. Each command changes one thing, and checks it first: a mistyped command or value changes nothing. While the cell runs, most changes are made at once, and its phones keep their service.

The first time, the core must allow the cell: celld shows the command to run on the core, and the fingerprint to check there.

A new cell doesn't go on the air by itself. Once its core has allowed it, it stands by, and celld shows which carriers the network has: tick the bands and carriers the cell should use in the menu (under Settings, or "Go on the air"), or say them with "celld set band"; "celld confirm" takes any of them. Only then does it send anything. A cell set up before this was so carries on as it was.

A cell is only on the air where its networks have carriers. A new network has none until its administrator chooses some, and a network may have none in the band a cell asks for: the cell then waits, off the air, and takes a carrier as soon as its core says there's one. A cell on a carrier which none of its networks has any longer leaves it. The menu only offers the bands and carriers the cell's cores do, each with the networks which have it. A cell which serves several networks is on the carriers of whichever has one for what it asks, and serves all of them there.

"celld set override on" lets the cell use carriers its cores don't offer: its cores then put it on those it names, theirs or not. This may violate network assignment agreements, so the menu asks before it's turned on.

A cell can be a relay, with no link of its own to the core: activate the computer as a phone of the network first (with "cell activate"), then run "celld add 10.64.0.1" (the core's gateway address, or any of the core's addresses), and the cell reaches the core through its own phone. A relay's phone never uses a cell behind it, and the relay only serves phones while its own phone has service.

ex:
"celld" opens the cell's menu: how the cell is doing, its cores and its settings, each of which can be changed where it's shown, with the keyboard or the mouse. Everything in it can also be done with the commands below.
"celld status" says how the cell is doing, and its settings.
"celld add core.acme" runs a cell of the network whose core is core.acme. Any name or address will do, whatever it's called.
"celld add core.beta" makes it one cell for two networks, whose operators share it (as for a cell site in a quiet area, which neither would build alone). It connects to both cores, each of which must allow it, and serves each network's phones, and phones roaming on either. Each network sees the cell as one of its own. If one core is lost, the cell carries on serving the other network. Adding a core doesn't disturb the networks it serves already.
"celld remove core.beta" stops serving that core's network (or give the network's name), and carries on serving the others. A cell with no cores left stops.
"celld set area 3" puts the cell in tracking area 3 (0 at first).
"celld set band b3" puts the cell on one of its core's carriers in band 3 (1800MHz): "b3", "3" and "1800" all mean it. Each cell is on one carrier, which its first core picks, and phones reach it on a channel of its own there. Lower bands (b31, b28, b20, b8) reach further and through more; higher ones (b3, b1, b7) carry phones in a busy place. The cell won't go to a band none of its networks has a carrier in ("cellcore spectrum" on the core adds one).
"celld set band b20 b3" makes this computer a site with several bands: it runs a cell on each, here one in band 20 for reach and one in band 3 for room, on the one modem (so with the one power). To phones each is a cell of its own, and they move between the two as between any cells: up to the higher band where it's strong enough, down where it isn't. A band may be named several times, for a cell on each of several of its carriers, and a carrier by name ("celld set band b20 b3/1 b3/2"): up to 8 cells, one on a carrier. What a core has no carrier for is left out, and celld says so.
"celld set interval 4" makes the cell send its system information every 4 seconds (0.5 to 10), whatever its core says.
"celld set name HILL-1" names the cell site (up to 8 characters, spaces too, as in "celld set name Old Mill"): each of its cells says it in its system information, and phones' cell monitors show it with the cell. Anyone can give a cell any name, so it says nothing about whose a cell is.
"celld set pos 120 70 -340" makes the cell say where it is (its computer's position, as F3 shows the block), so phones can work out where they are from how far away each cell is ("cell locate"). Cells far apart, and at different heights, give phones the best positions.
"celld set power 40" makes the cell send with 40 dBm (placed computers may go up to 50), to reach further. A cell sends with 30 dBm unless it's told otherwise: phones send with 23 dBm, and cells hear 7 dB better than pocket computers and turtles do, so at 30 dBm a phone which hears the cell can answer it. A stronger cell is heard where its phones can't reach it, and they find it unanswering: it suits a cell phones only need to hear (to work out where they are, say), or a site whose phones send with more.
"celld set service sms" makes the cell only carry messages, as a satellite does: up high, strong, and heard far away, it's for when there's nothing else (off-grid, or in an emergency). Phones use their own network's full cells first, and partners', and only then such a cell (or another network's, only once nothing else will do), and go back as soon as they can, unless told to use its network. On it, they send and receive messages, but have no route for packets. "celld set service full" makes it carry everything again.
"celld set override on" lets the cell be put on carriers its cores' networks don't have, such as "celld set band b7/3" where no network has band 7. "off" takes it off them again.
"celld confirm" puts a new cell on the air, on the bands it's set to, or any if none were set.
"celld unset pos" puts a setting back as it is when it's not set: area 0, any band, as often as the core says, no name, not saying where it is, 30 dBm, carrying everything, and no override.
"celld stop" stops the cell, and it doesn't start with the computer. "celld start" starts it again.
"celld restart" starts the cell again at once, connecting to each core afresh. Its phones lose service for a moment. So does changing its area, or its bands to others, as the cell says them to its cores when it connects.
