celld runs a cell of a cellular network: a tower which phones attach through. It runs in the background, starts with the computer, and keeps the computer running when nobody is nearby. It reaches the network's core over any route (a cable, a radio link, or the cell's own computer), and tries again if it loses the core.

The first time, the core must allow the cell: celld shows the command to run on the core, and the fingerprint to check there.

ex:
"celld core.acme" runs a cell of the network whose core is core.acme.
"celld 10.0.0.1 3" runs a cell in tracking area 3.
"celld" shows how the cell is doing.
"celld stop" stops the cell.
